# Darwin's Desk: releases

Signed installers of Darwin's Desk (The Darwin Project) and the notice the app reads to offer an update.
No source code here.

- Each release holds the installer (`.exe`, signed "CN=The Darwin") and `latest.json` (`version`, `url`, `sha256`, `notes`).
- The app only installs a file from a release of this repository whose SHA-256 matches the notice and whose code signature is ours.
